<h1 align="center">Aira's Little Birthday World</h1>

## Dear baby,

I built this little world just for you, because I love you more than words can say. Every tiny flower, floating island, and birthday surprise was put here with you in mind.

You make ordinary days brighter just by being you. I hope this little corner of the world reminds you how deeply you are loved—not only on your birthday, but every day. May the year ahead bring you laughter, gentle days, brave dreams, and all the beautiful things your heart deserves.

Happy birthday, my love. This world is yours, always.

With all my love,  
-JC

---

## About this project

- Run `npm run dev` to preview the birthday world.
- Run `npm run build` to create the production site in `dist/`.
- Edit the `content` object near the top of `src/main.js` to personalize the birthday messages and memories.
